# Restaurant Menu Page

A simple static website for Foodie Restaurants, showcasing their menu items categorized by meal times: Breakfast, Lunch, Snacks, and Dinner.

## Description

This project displays a restaurant's menu with images of various dishes. The homepage introduces the restaurant, and separate pages are dedicated to each meal category. The site features a navigation bar for easy access to different sections.

## Features

- Homepage with restaurant introduction and image
- Dedicated pages for Breakfast, Lunch, Snacks, and Dinner
- Navigation bar linking all pages
- Responsive design with CSS styling
- High-quality images of menu items

## Technologies Used

- HTML5
- CSS3

## Usage

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Use the navigation bar to browse different meal categories

## Project Structure
